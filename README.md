# 文章題シアター（中1数学 一次方程式の文章題・テスト復習）

アニメーションで文章題の場面を見てから、いつものルール（1行に1つの操作、右はしにメモ）で式を書いて解く学習ゲームです。

- `index.html` 1ファイルで動作（サーバー・ビルド不要）
- 記録はその端末のブラウザ（localStorage）にだけ保存
- 効果音・アニメは「せってい」で OFF にできます

## Day1 / Day2

ホーム画面で選びます。

- Day1（ゲームだけ）：書き方の見本 → 追いつく → リボン → 鉛筆（各2問）。紙はやらない
- Day2（ゲーム＋紙）：書き方の見本 → 各問題1問（紙と同じ形）→ 終わるごとに結果レポートの紙ミッション

## 書き方の見本（最初にやろう）

6つのルール（1マス1文字／＝を縦にそろえる／マイナスははっきり／1行1操作＋メモ／検算は（　）付き／答えの欄を全部うめる）を、きちんと書けた例 → ○✕クイズ（なぜ？つき）→ ダメな例のバグさがし（6つ）→ 直した例、の順で身につけます。

## 1問の流れ（いつも同じ4ステップ）

1. アニメで見る（場面を動きで見て「わかったこと」を確認）
2. 表を書く（x は何か → 表のマスを順にうめる → 同じものを ＝ でつなぐ）
3. 式をルールで解く（メモ「かっこをはずす／移項／まとめる／両辺÷○」を選んでから次の行）
4. 検算と答え（元の式に代入して左辺・右辺 → 答えの欄を全部うめる）

## 問題

- 追いつく問題（先に出た人の時間を x にする形）
- リボンを分ける問題（全体が分かっている比）
- 鉛筆を配る問題（過不足）

各2問（ヒントあり → 紙と同じ形）。問題はすべて自動生成のオリジナルです。
